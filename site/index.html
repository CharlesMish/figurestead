Evidence, given a disciplined visual voice.

Figurestead is an experimental scientific-figure system for Python and the browser, built around a shared normalized figure contract.

Six selected themes show how one scientific grammar can move between quiet foundations and expressive signatures without changing the underlying evidence.

03

One theme, two runtimes

Python and browser surfaces share the normalized figure-contract vocabulary and selected theme definitions. Each surface renders through its own runtime implementation; shared semantics do not imply pixel-identical output.

Python

figurestead on PyPI

python -m pip install "figurestead==0.9.0a1"
from figurestead import line
figure, axes = line([0, 1, 2], [[0, 1, 0]])

Browser

@figurestead/web on npm

npm install @figurestead/web@0.9.0-alpha.1
import { createFigurestead } from "@figurestead/web";
createFigurestead(document.querySelector("canvas"), contract, { reducedMotion: true });

Source and working examples: CharlesMish/figurestead.

04

What this alpha is not

This experimental alpha features six themes from a broader design catalog. Recommended color-led series capacity is explicit; the six-series signature studies rely on marker and dash redundancy beyond that recommendation. Digital paper evidence records a measured 6.372 pt minimum label against a 6 pt floor, without physical printer proof. This is not universal accessibility, renderer, projector, or physical-print certification.
