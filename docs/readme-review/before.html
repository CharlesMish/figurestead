Figurestead experimental public alpha

Figurestead is a framework-free scientific figure system for deterministic, inspectable Python and browser output. This experimental alpha contains six curated themes and uses Slipware as the default. Presentation profiles are independent from themes. The monograph profile is available through get_profile("monograph") and remains unavailable through get_theme.

Python package: figurestead 0.9.0a1. Browser package: @figurestead/web 0.9.0-alpha.1. Source: https://github.com/CharlesMish/figurestead.
