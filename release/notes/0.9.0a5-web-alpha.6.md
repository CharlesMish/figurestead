# Figurestead a5 / alpha.6 candidate

Prepared from reviewed main `e729f3c030b5ccf0764933f710957bcea47ee636` after normal merges of
PR51, PR53, PR55 and PR52. Proposed package identities: Python `0.9.0a5` and
browser `0.9.0-alpha.6`. **Candidate only: owner review and separate publication
authorization are pending.** No registry tag or public release is created by
this preparation. Published a4/alpha.5 artifacts and historical evidence remain
unchanged.

## Changes

- Python note footers and strip sample counts are measured outside the data
  rectangle. Notes wrap and are remeasured for resize/export; inadequate margins
  raise guidance. Caller-owned axes retain caller-owned margins.
- Explicit histogram edges warn when they exclude observations. Shared-bin
  comparison recipes disclose complete sample counts, medians and exclusions.
- `save_figure` stages a single path export and replaces the destination after
  success; failures preserve an existing destination and clean temporary output.
  SVG external-image mode is rejected. Streams and multi-file output remain
  outside this helper's scope.
- Optional Python signatures use measured spare footer space, disappearing when
  they would overlap. They do not reserve margins or suppress note errors.
- Browser Canvas now paints reference and row bands. A closed `Mark` union,
  `MARK_KINDS` and explicit unknown-kind failures align the scene pipeline.
  Opaque custom-renderer evidence reports incomplete coverage; custom live Canvas
  drawing remains supported. Arbitrary custom drawing is not shared SVG output.
- Package onboarding is bound to the new versions and retains executable
  examples. The root development lock patches `source-map-js` to 1.2.2;
  historical gallery locks and published specimen bytes are preserved.

## Boundaries

Python >=3.10 / Matplotlib >=3.7 / NumPy >=1.24 / Pillow >=10 and browser
Node >=22.22.0 are unchanged. Schema 0.4 and renderer API 1 are unchanged.
Reference-theme and direct-label designations do not expand. Canvas/SVG parity
means the checked geometry and marks, not identical raster pixels. The existing
optional whole-source TypeScript audit remains separate from packed consumer
declaration checks. Historical gallery images are not regenerated for this
candidate.

## Review local archives

wheel or sdist from `release/python/0.9.0a5/dist/`, or the npm tarball from
`release/npm/0.9.0-alpha.6/dist/`. Authenticate it with the adjacent
`SHA256SUMS.txt` first. Candidate versions are not yet available from registries;
the package-embedded onboarding uses the eventual version-specific install pins.

The new coordinated record in `release/reviews/0.9.0a5-web-alpha.6.json` identifies
the producing commit, tools, source ledgers and retained bytes. The retaining
commit is separate to avoid circular provenance. Review must use those exact
archives. Rebuilding is verification, never a substitute publication artifact.

Python publication remains manually gated by protected main, exact commit,
typed confirmation and identical TestPyPI bytes before PyPI. npm remains manually
gated by exact commit, version, hash and dist-tag. No workflow dispatch is
authorized by candidate preparation; any later publication requires the owner's
