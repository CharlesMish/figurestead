# Figurestead next alpha — Python 0.9.0a2 / web 0.9.0-alpha.3

Proposed GitHub prerelease tag: `v0.9.0-alpha.3`. Preparation only; these notes do not announce publication.

More dependable series identity in scientific line figures: persistent marker identities and truthful legends, with optional direct labels that reuse the same identity. Lavender Fog Notebook and Ultraviolet Laboratory provide documented light/dark exemplars for the bounded three-series profile.

- **Changed default line rendering:** the first three series use open circle, square and upright-triangle identities, with own-line-only clipping beneath markers and matching line + marker legends. Other data/grid content is not erased by an opaque marker fill. **Existing line figures may look different after upgrading.** Default line rhythm remains solid and independent of marker identity.
- **Python `series_slots`:** carry original nonnegative slots through filtering/reordering to preserve color/edge and marker identity. Labels remain display text.
- **Browser keyed identity:** supported `setData` updates retain established identity; partial overrides preserve omitted identity fields. `setConfig` remains explicit replacement/reset behavior.
- **Opt-in direct labels:** `line(..., direct_labels=True)` / `style.directLabels: true` place actual body identities beside eligible ordinary one-panel, 2–3-series line figures. Ordinary legends remain the default; unsupported text/geometry/layout or insufficient measured fit falls back as a whole. Printable ASCII is literal; Unicode/multiline/math interpretation and multi-panel/animated direct labels are outside v1. Active browser transitions and unmeasured exports use ordinary treatment.
- **Reference-theme documentation:** Lavender Fog Notebook is reference light and Ultraviolet Laboratory reference dark for the documented bounded three-series line profile. No default-theme selection, universal accessibility/CVD-user claim or print qualification is implied. Direct labels do not automatically inherit that designation.
- **Explicit rendered-series contrast APIs:** Python `rendered_series_audit` and browser `renderedSeriesAudit` accept explicit single-layer substrate/opacity/compositing facts, distinct from the unchanged static theme audit. These APIs were absent from the retained published Python a1 and npm alpha.2 artifacts. The existing exact 3:1 floor is unchanged.
- **Python typography:** shipped title typography explicitly requests the regular weight already selected, avoiding fallback diagnostics without changing its tested appearance or custom Profile semantics.

Python and npm counters are independent. Eventual npm publication uses `alpha`; `latest` is not changed. Use exact package versions for reproducibility or `@alpha` intentionally to follow the npm prerelease channel. Shared semantics do not promise cross-runtime pixel or unconditional fit equivalence.
