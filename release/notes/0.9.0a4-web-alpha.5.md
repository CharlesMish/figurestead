# Figurestead alpha.5 candidate — Python 0.9.0a4 / web 0.9.0-alpha.5

Prepared 2026-10-04 for independent artifact and owner review. **Unpublished;
not authorized for publication.** The proposed coordinated tag is
`v0.9.0-alpha.5`; it has not been created. Public Python a3 / browser alpha.4,
their tags, artifacts and retained visual evidence remain unchanged.

## Maintenance changes since a3 / alpha.4

- **Standalone browser SVG typography and subtitles (PR43):** exported ordinary
  text inherits the existing system monospace stack, and wide, paper and
  multi-panel local headers include authored escaped italic subtitles. Compact
  header policy, Canvas, accessible descriptions and scientific geometry are
  unchanged. Fonts remain host-dependent; this is not pixel parity or a general
  long-header fitting policy. See [SVG scope](../../docs/svg-export-typography.md).
- **Dense browser numeric-array admission (PR44):** holes and inherited numeric
  slots reject with indexed configuration errors before line/scatter/strip
  compilation or controller mutation. Valid dense finite data follows the same
  path. Null, undefined, NaN, infinities, typed arrays and empty numeric arrays
  remain invalid; this does not implement browser missing observations.
- **Python DirectLabels lifecycle (PR45):** stale planners, overlays and owned
  draw/export hooks retire after axes clearing/reuse without discarding caller
  wrappers, positions, unrelated artists or another axes' owner. Cleanup is
  lazy until draw/export or a valid plotting call. Append/reuse keeps a complete
  ordinary legend where required. Admission and the placement solver do not
  expand. See [direct labels](../../docs/direct-series-labels.md).
- **Python categorical-matrix authored domains (PR46):** colorbar construction
  no longer broadens representable authored bounds. Exceptional colorbar display
  coordinates stay separate from the image's scientific norm, with original-unit
  endpoint labels. Native norm/cmap/limit updates, nested replacement and removal
  ownership retain their documented behavior. Unrepresentable positive finite
  spans reject before axes mutation. Numeric data, status cells and the existing
  ramp are unchanged. See [domain scope](../../docs/categorical-matrix-domains.md).
- **Declared-minimum Python compatibility (PR47/48):** owned line markers use the
  existing round join default; masked marker centers are omitted from circular
  clipping without changing offsets or line data. Masked direct-label geometry
  falls back to the ordinary legend. Owned regular headings use the equivalent
  named `normal` weight so SVG text export works on older supported Matplotlib.
  Custom profiles and caller font overrides retain their existing semantics.

## Compatibility and visible limits

Dependency floors remain Python >=3.10, Matplotlib >=3.7, NumPy >=1.24 and
Pillow >=10; browser consumers remain Node >=22.22.0. Repository/release tooling
stays on Node 24.17.0 / npm 11.13.0. Schema 0.4 and renderer API 1 are unchanged.
Sparse browser arrays that were accidentally admitted now reject. SVG text,
axes-reuse layout and narrow-domain matrix colors/labels can visibly change
where the repaired paths apply. Arbitrary caller numeric font weights retain
upstream Matplotlib behavior.

No categorical-matrix ramp migration, histogram bin-policy change, browser
null/gap contract, long-header layout solver, arbitrary direct-label extension
or new reference-theme qualification is included. The documented extreme
matrix-domain arithmetic limit remains; finite domains are not universally
qualified. S1–S3 reference boundaries, retained provenance, simulation limits,
and absence of CVD-user/print certification remain intact.
