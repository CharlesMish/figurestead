# Figurestead alpha.4 — Python 0.9.0a3 / web 0.9.0-alpha.4

Candidate preparation, 2026-09-27. Proposed tag: `v0.9.0-alpha.4`. These versions are not yet published; install the retained files for review. Published installation guidance remains Python a2 / web alpha.3 until registry verification succeeds. Python/npm counters are independent; eventual npm publication uses `alpha`, leaving `latest` unchanged.

**More faithful scientific figures through explicit rhythm and marker-density control, honest Python missing-data breaks, corrected quantitative encodings, and stronger identity and scene integrity.**

## Changes since a2 / alpha.3

- **Python subtitle containment:** renderer-measured wrapping preserves fitting single-line subtitles and contains narrow headers across draw/resize/DPI/export cycles. Genuinely insufficient header capacity raises clearly rather than silently clipping text.
- **Python authored rhythm:** `series_keys` + keyed `line_styles` address solid/dash/dot/dash-dot independently of `series_slots` marker/color identity and display labels. Authors supply scientific meaning. Browser keyed rhythm already existed; it is not a new browser API.
- **Direct-label rhythm samples (both runtimes):** when any participating line is non-solid, every direct-label row includes its resolved line sample before marker and text. Leaders remain neutral. Extra width may cause atomic ordinary-legend fallback; all-solid treatment remains compact.
- **Opt-in marker density (both):** Python `marker_stride` / browser `style.markerStride` select markers by original authored index with endpoint preservation. Default cadence is unchanged. This is presentation control, not sampling, downsampling, or scientific inference; unmarked observations remain in the line but lose an explicit sampling-location glyph.
- **Browser continuous rhythm:** Canvas/SVG preserve authored phase across segment subdivision and own-marker holes; marker clipping hides ink without restarting the path.
- **Python explicit NaN-y breaks:** ordinary static lines retain maximal finite runs, their endpoints and isolated observations without bridging, interpolation or imputation. Shared x stays finite. Infinities, masked arrays and alternate sentinels remain unsupported; all-missing rows reject before mutation. Rhythm restarts at true gaps. Gapped direct-label requests fall back atomically. Browser/portable missingness is not implemented.
- **Python heatmaps now use a theme-derived sequential ramp with monotone lightness, replacing the field/panel/primary/summary token sequence. This changes heatmap colors while preserving data and normalization. Theme palettes and line-series identity are unchanged. The categorical-matrix extension retains its existing rendering until its separate migration.** Light themes darken as values increase; dark themes lighten. Quantized plateaus are allowed; no claim of perceptual uniformity or 256 distinguishable levels follows.
- **Multi-dataset Python histograms:** dataset-colored median rules and paired fill/rule legend readouts report ownership and median values. Coincident medians remain coincident. Single-dataset appearance, counts, bins and median coordinates are unchanged.
- **Unconfigured browser line series now remain solid at every series count. Explicit rhythm styling and existing marker/color fallback allocation are preserved.** The auxiliary Python scene compiler shares this implicit default.
- **Keyed identity and scene integrity:** browser newcomers get persistent first-encounter ranks; failed updates consume no ranks, removed keys retain theirs, and `setConfig` remains replacement/reset. Empty strip categories retain positions without fabricated medians. Point-only lines have marker-only legends in Python/Canvas/SVG. Collision-safe semantic IDs and document-unique SVG resources preserve ownership for distinct keys.
- **Python auxiliary consistency:** `compile_terminal_scene()` rejects non-finite line/scatter geometry and respects explicit glyph/rhythm blocks. It is not NaN-gap transport. Scatter/strip colors and legend order follow first appearance per fresh call, not persistent B2 slots across calls.

## Compatibility and limits

Existing figures may visibly change: heatmap colors, multi-dataset histogram median/legend treatment, browser implicit overflow rhythm, point-only legends and Python scatter/strip color ownership differ as described above. Formerly colliding unsafe identifiers/fingerprints may change; safe IDs remain stable where applicable. Authored rhythms and deterministic fallback markers remain supported. Subtitle layouts that truly cannot fit may now reject.

B2 persistent S1–S3 identities, `series_slots`, baseline direct labels and the bounded Lavender Fog Notebook / Ultraviolet Laboratory reference designation **already shipped in a2/alpha.3**. They are the foundation, not additions in this release. Default theme selection and palette values are unchanged. Higher-series fallback remains unqualified, crowded/coincident observations can remain ambiguous, and tiny gaps may resemble dash spaces.

Direct labels retain the 2–3-series, printable-ASCII, ordinary-layout/measurement/export restrictions and whole-legend fallback. No Unicode/multiline/math, browser gap support or new plot-family qualification is added. Histogram bin policy, categorical-matrix ramp migration and ordinary long-legend pressure remain separate. No CVD-user, print or universal accessibility claim is made. The documented npm consumer-repacking limitation remains; ordinary installs/imports are supported.
